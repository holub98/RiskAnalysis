MERN aplication </br>
Application which measure risk on foreign market </br>
Application doesn't have responsive design

Application was created with ReactJS and JavaScript on frontend.
Backend of appliaction uses NodeJS and Exxpres JS. 
It was NoSQL database.
Charts are generated with plotlyJS.
Also app use APIs "Alpha Vantage".

If you want to start you should have Node version 16 or higher.
You can start application only on backend folder, frontend was builded. 

Command to start: ""npm run start""
